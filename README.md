# Music Free V4.1.1 — 搜索精度与直接播放稳定版

面向 macOS 的本地优先音乐中心：开放音源搜索与发现、原唱/版本优先匹配、歌曲资料目录、YouTube/Bilibili 允许范围内的官方视频嵌入、本地音视频轨处理、歌单/历史、歌词和沉浸式播放界面。

**重要边界**：免费匿名的开放音源不等于主流商业音乐的完整授权曲库。找不到对应歌手的完整可播放音源，会明确提示，不会把同名的其他歌曲伪装成原唱。YouTube/Bilibili 不提供未授权视频抽轨或绕过访问控制功能。

## 环境要求

- macOS，Node.js 22.5+；建议 Node 22 LTS（你此前的 22.23.2 可以继续使用）。
- 网络：首次 `npm install` 和在线搜索需要联网。纯本地音乐在已安装后可离线播放。
- 可选：通过本机 `.env` 文件配置 YouTube 官方 API Key；不填 Key 时官方搜索入口及粘贴公开视频链接仍可用，API 自动检索/热门元数据会受限制。
- 这份 Git 仓库是本地离线 Git 历史，不要求 GitHub 账号或远程仓库。

## 安装与运行

在 Terminal 进入解压出的 `music-free-v4.1.1` 文件夹：

```bash
npm install
npm run verify
npm run dev
```

浏览器访问 **http://127.0.0.1:5173**；关闭服务在终端按 `Control + C`。

`npm run verify` 包含自动化测试、TypeScript 检查和 Vite 生产构建。当前交付环境对 npm registry 的访问有限，**真实生产构建与浏览器播放仍需要你在 Mac 上复验**；请不要把静态检查通过理解成已完成所有平台的实际播放验收。

## V4.1.1 — 本轮重点修复

- **四个搜索意图识别**：`星星（俄罗斯高音的）` → Vitas《Звезда/星星》；`陈楚生 -庙堂之外` → 陈楚生《庙堂之外》；`黄昏 - 周传雄` → 周传雄《黄昏》；`路虎` → 歌手陆虎，并展示《雪落下的声音》的已核对资料。
- **泛用的歌名/歌手分离**：识别 `歌手 - 歌名`、`歌名 - 歌手`、已知简繁/外文别名。其他未核实歌曲不会使用虚假的原唱标记。
- **Apple 目录搜索修复**：优先使用标准化查询、最多三个地区搜索，补充严格歌手筛选，优先显示有来源依据的已核对记录；网络失败仍可显示少量已核对资料。
- **即时搜索反馈**：已核对目录资料立即显示，不必等其他音源接口超时；过期请求会取消，避免旧搜索覆盖新结果。
- **一键播放**：在当前页面寻找对应独立音源；没有可用独立音频时，对已核对的歌曲自动切到当前页的官方视频播放器，**不需要在无关候选歌曲中再选一首**。
- **已核对官方视频**：Vitas《Звезда》、陈楚生《庙堂之外》、周传雄《黄昏》、陆虎《雪落下的声音》，均通过公开的官方发布者或官方艺人频道资料核对。YouTube 官方嵌入可能受地区、版权或浏览器自动播放策略限制，**不能保证每个地区都可播放**。
- **播放状态修复**：调用 `play()` 与缓冲等待并行进行，避免先等待长时间缓冲造成用户点击激活失效；播放失败清除旧歌曲状态；同歌备用音源坚持歌手/版本严格检查。
- **后台自动发现**：缩短本地服务新装启动时的发现轮询，继续用 SQLite 保存快照、重试和健康数据。YouTube/Bilibili 视频不冒充独立音频。
- **自动测试**：新增 `npm run test:songs`（四个指定场景、模拟 Apple 目录、拒绝错播及离线）、`npm run test:buffer`（缓冲状态）。

### 重要的“能播放”边界

这四首的**音乐资料与官方视频身份**已经核对、并有可复现的自动化回归测试；但这**不代表**四首商业录音在免费开放音源中存在可直接播放的完整音频文件。

点击「一键播放」时先匹配可用独立音频，失败后若有已核对官方视频则在 Music Free **本页面**显示 YouTube 官方嵌入；不是媒体流提取，也不是 Music Free 自己托管的商业音乐。平台可能禁止嵌入或要求用户在视频中再点一次播放，无法保证远程真实播放。

### 快速检查指定歌曲

```bash
npm run test:songs
npm run test:buffer
npm test
npm run verify
```

`npm test` 为无网络、可重复的逻辑及本地服务测试；`npm run verify` 还要求安装依赖并完成 TS/Vite 构建。最终真实视频播放、各站音源可达性和浏览器媒体限制需在 Mac 上检查。具体请见 `TEST_REPORT.md` 与 `TEST_PLAN.md`。

## 数据存储与隐私

- 浏览器 IndexedDB/localStorage：歌单、收藏、历史、播放快照、歌词、本地媒体索引。
- 本机磁盘 SQLite WAL：后台任务、发现元数据快照、音源健康记录。默认 `~/.music-free/`。
- 本地视频经 FFmpeg.wasm 在浏览器内存中处理，**不上传服务器**。
- 不长期存储从第三方流媒体获取的音频/视频字节。
- 提示：安装新版本若保留同一浏览器和 `127.0.0.1:5173` 地址通常可延续浏览器数据，但请备份原数据；切换域名/浏览器 Profile 不会自动迁移 IndexedDB。
